# Puzzle Angar

Сайт для совместной сборки пазлов с друзьями.

## Запуск

```
cd C:\Users\noune\puzzle-party
npm start
```

Открой http://localhost:3000

## Как позвать друзей

Адрес `localhost` работает только на твоём компьютере. Варианты:

1. **Одна Wi‑Fi сеть.** При запуске сервер печатает адрес «в локальной сети», например `http://192.168.1.5:3000`. Его и отправляй. Если Windows спросит про брандмауэр, разреши доступ для Node.js.
2. **Друзья в другом месте (туннель).** В отдельном окне:
   ```
   npx localtunnel --port 3000
   ```
   или, если установлен cloudflared:
   ```
   cloudflared tunnel --url http://localhost:3000
   ```
   Выдаст публичную ссылку https://…, открой через неё комнату и нажми «Позвать».
3. **Постоянный хостинг.** Проект без сборки: любой хостинг с Node.js (Render, Railway, VPS). Команда запуска `npm start`, порт берётся из переменной `PORT`. Папку `data/` нужно держать на постоянном диске, там лежат картинки и прогресс.

## Что умеет

- Своя картинка (файл, перетаскивание или Ctrl+V), галерея и вкладка **Darklay**: сплошной белый, чёрный, бетон, туман, шум, фрактал, муар, клубок.
- От 6 до 100 000 кусочков. Рендер на WebGL2, 100 000 кусочков тянет обычный ноутбук.
- Все игроки двигают кусочки одновременно, видят курсоры друг друга. Кусок, который кто-то держит, подсвечен цветом этого игрока и для остальных заблокирован.
- Стыковка: поднеси кусок к соседу, он защёлкнется со щелчком.
- Инструменты: «Края» (только кусочки с краем), «Подсказка» (бледная картинка на поле), «Картинка» (образец), цвет стола (для белых и чёрных пазлов), звук, чат, двойной клик ставит отметку для всех.
- Счёт: кто сколько соединил. Прогресс сохраняется на сервере.

Управление: колесо зум, тащить фон двигать стол, на телефоне щипок. Клавиши `E` края, `G` подсказка, `P` картинка, `F` весь стол, `Enter` чат.
